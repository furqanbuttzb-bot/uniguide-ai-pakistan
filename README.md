🎓 UniGuide AI Pakistan

An AI-powered university admission guidance platform for Pakistan that helps students discover HEC-recognized universities, explore degree programs, estimate admission chances, and receive personalized admission guidance through an AI Counselor.

---

 📌 Problem Statement

Every year, thousands of students in Pakistan struggle to find accurate information about universities, admission criteria, merit trends, entry tests, and available degree programs. Information is scattered across multiple university websites, making the admission process confusing and time-consuming.

UniGuide AI Pakistan solves this problem by providing a single platform where students can search universities, explore degree programs, predict admission chances, and receive AI-powered guidance.

Target Users
- Intermediate students
- Gap year students
- University applicants
- Parents
- Career counselors

# 🚀 Features

 🔍 University Finder
- Search HEC-recognized universities
- Filter by:
- Province
- City
- Degree Level
- Degree Program
- University Type (Public/Private)

 🤖 AI Counselor
- AI-powered admission assistant
- Answers admission-related questions
- Suggests suitable universities
- Provides eligibility guidance
- Explains admission procedures

 📊 Admission Predictor
- Predicts admission chances
- Uses student academic information
- Estimates admission possibility

 📅 Entry Test Information
Provides information about major admission tests including:

- MDCAT
- ECAT
- NTS
- NET
- LAT
- HAT
- FAST Entry Test

 🏛 University Information
- HEC-recognized institutions
- Degree offerings
- Basic university information

---

🤖 AI Feature

The AI Counselor is powered using Google's Gemini API.

It helps students by:

- answering admission questions
- suggesting universities
- explaining eligibility
- guiding students through the admission process
- recommending suitable degree programs

 System Prompt

The AI is instructed to:

- Act as a professional Pakistani university admission counselor.
- Recommend only HEC-recognized universities.
- Provide clear, accurate, and student-friendly responses.
- Avoid making unsupported claims.
- Guide students based on their academic background, interests, province, and preferred degree.
- Explain admission requirements and entry tests whenever applicable.

 ⚙️ How to Run the Project

Clone the repository

https://github.com/furqanbuttzb-bot/uniguide-ai-pakistan

Open the project

uniguide-ai-pakistan

Install dependencies

npm install

Create a `.env` file

env
VITE_GEMINI_API_KEY=YOUR_API_KEY

Run the development server

npm run dev

Open your browser and visit:

http://localhost:3000
